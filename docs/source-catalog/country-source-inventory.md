described in the OppSift master prompt. Each row captures the minimum evidence
needed for a compliant approval decision. A country appearing in the approved
scope is not evidence that its sources have been inventoried, permission-
reviewed, or technically validated. Rows marked `discovered` are leads only.

## Intake rules

- Use only the approved country list in `launch-countries.md`; do not add
  markets without a product-owner decision.
- Use official publishers and primary documentation as the evidence source.
- Treat source discovery, permission review, technical assessment, and activation as separate stages.
- Keep licensing, attribution, rate limits, and robots restrictions visible beside connector design.

## Source inventory notes

1. A row is not an approved integration simply because the site is public.
2. Every future country entry must include direct evidence from the publisher or its official docs.
3. The intake table is an initial snapshot, not the complete inventory.
   Use the machine-readable source catalogue and supplemental evidence
   documents for the current candidate count and research status.
4. Source categories must be tracked separately from the internal OppSift taxonomy (`government`, `grants`, `commercial`).
5. The same source may be valid for more than one category, but the approval decision must be category-specific when terms or licensing differ.

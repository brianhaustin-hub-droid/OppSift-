## Commercial source discovery considerations

1. Research registration, vendor-approval, and data-use restrictions before activating a commercial source.
2. Separate supplier-registration portals from project/tender listings because their lifecycle and data quality differ.
3. Use category and market-specific evidence to avoid false assumptions about what is public, permissive, or commercially restricted.
4. Review the source's original value fields and deadlines carefully because commercial listings often use inconsistent taxonomies.
5. Track attribution, usage, and redistribution terms separately from technical access feasibility.
